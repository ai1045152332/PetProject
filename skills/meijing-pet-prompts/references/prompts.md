# 美境 CLI 生成宠物姿态素材 —— Prompt 存档

> **方案：每个状态只做 1 帧静态图**（共 5 张：休闲/睡觉/抚摸/专注/躲藏；原「提醒 warn」状态已合并进专注，不再生成）。
> 呼吸、状态切换等动画交给 App 渲染层实现，**不再让 AI 逐帧生成多帧动画**。
> 用于给 DesktopPetForMacApp 生成 5 状态的宠物姿态图。
> 平台：美境 AI 设计师（内网），生成模型：`gpt-image-2.5-sunburst-vision`
> 参考图：真实猫咪照片（银渐层英短，S3：`https://s3plus.sankuai.com/aigc-warehouse/skillopen/5d7cd9e2-da1b-4142-88d4-da37bebdd683.jpg`，有效期 24h，过期需重传）作为身份锚点；旧锚点曾用项目内置 `Sprites/idel/idle_0_副本.png`

## 用法说明

- 每个状态 `generate.py "<组装后的 prompt>"` 提交 1 张，再 `poll.py` 轮询取图
- 参考图用 `[@image:#1]` 占位符插入开头，末尾附 `For Image #1: URL: <S3 URL>`
- 通用后缀（保持一致）：`3头身Q版卡通可爱风格，干净浅色纯色背景，画面中只有这一只猫，无文字无水印`
- 每状态产出 1 张 PNG，放入 `Sprites/{state}/frame_00.png`（`SpriteSheet` 单帧加载即可，呼吸由渲染层缩放实现）
- **背景必须显式写「不要地面阴影」**：模型默认会给猫加一块浅灰投影，抠图时投影与爪子连通、会被判成主体，深色壁纸下明显发灰；纯靠阈值/连通域去不掉，只能靠 prompt 从源头规避
- **抚摸态必须显式写「不要出现人的手」**：否则模型会画一只手在猫头上
- **躲藏态只画探出来的部分，且必须直立扒边**：上身竖直、一只前爪高举扒住画面左边缘，只画头、一小段前胸和那只扒边的爪，并显式禁止趴卧/伏低/下巴支地，否则模型会画成趴姿；其余身体不画（留在画面外），也不要画墙/屏幕边框，贴边裁切由 App 把窗口向外探出一小段完成

## 二、经验 & 已知问题（重要）

1. **只做单帧**：不再让 AI 逐帧生成呼吸动画——多帧间 AI 大小不可控（曾实测 8 帧 bbox 640~794，差约 25%），且统一尺寸后帧间无动作差异≈静止。呼吸感改由 App 渲染层对单帧做缩放实现。
2. **抠图必须连通域**：仅靠"亮度>235 去背景"会把耳朵尖/尾巴当噪点剔。用 BFS 最大连通域保留主体，只剔孤立小噪点。
3. **尺寸统一**：后期 resize 到同一像素尺寸（如 170×170）放 200×200 画布，保证各状态图对齐一致。
4. **通用帧后缀**：`3头身Q版卡通可爱风格，干净浅色纯色背景，纯白背景，猫身悬浮在背景中，脚下不要地面阴影、不要投影、不要影子，画面中只有这一只猫，无文字无水印` 能稳定命中 `gpt-image-2.5-sunburst-vision`。
5. **落地尺寸**：成图 1024×1024 → 抠图（BFS 从边界泛洪判背景 + 最大连通域保主体 + 2px 边缘带软过渡）→ 等比缩进 170×170 → 居中贴到 200×200 透明画布。实测五个状态主体高度统一为 162px，切换不跳动。
6. **躲藏态（hide）的隐藏效果不由绘图裁切承担**：只要画头、一段前胸、一只前爪，从画面左侧探出；App 贴边时窗口对齐屏幕边缘，并把素材裁切边钉在屏幕上（贴右边用镜像帧）。**落图时不要居中**：把主体左边缘对齐 200×200 画布的左边（x=0）、垂直居中，并按头部大小与休闲帧对齐（头高约 55~60px），不要把整体拉到 162px 高，否则头明显偏大。

## 三、动画帧（idel 休闲 / pet 抚摸）—— 单张基准图 + rig 骨架式变形

> 2026-10-28 落地并迭代。**帧数不再靠 AI 出多张关键姿态**，而是一张带动作的基准图交给 `--mode rig` 做局部形变。

- 帧数口径：App 内置 12fps 固定帧率（`PetViewModel.frameRate`），**帧数就是时长**——24 帧 = 2.0s。idel 取 24 帧循环、pet 取 24 帧一次性。
- 合成脚本：`DesktopPetForMacApp/tools/sprite_animate.py`（连通域抠图 → 主体高统一 164px、底边压第 181 行、水平居中 → rig 变形出序列帧）。
- rig 原理：给定骨根 `pivot`、旋转幅度 `amp_deg`、形变范围 `mask_poly` 多边形 + 羽化 `mask_feather`，对每个像素按固定点迭代反查源坐标做旋转采样，权重从骨根到末端平滑衰减，因此接缝不断、不会出现「第二个尾巴」。
- **必须用 `mask_poly` 圈肢体，不能只用 `gates` 轴对齐软边界**：尾巴根贴着右后腿、脖子根贴着后背，矩形门一宽就会「尾巴动后腿也动」「头动后背也动」（用户实测反馈）。
- 帧序列由正弦驱动、一轮 `cycles` 个周期，**首尾天然无缝**；帧间差可以调到 1/255 量级，目视就是丝滑。

### 实测弃用的两条路（别再走）
1. **AI 出 2~4 张关键姿态 + 保持/交叉淡化排帧**：用户反馈原话——「动的太呆了 第一个好像在瞬移」；12fps 下持续 0.5~1s 不动的姿态切换就是瞬移感。
2. **光流位移场插值（`--mode flow`）**：块匹配会把细尾巴扇成一片、把歪头拉变形，出现重影。
3. AI 想直接表达「大幅歪头」时，模型还会顺手改比例（腿变短、头变大），所以基准图只要求**小幅带动作**，幅度交给脚本参数控制。

### idel 摇尾巴（当前落地）
```bash
python3 tools/sprite_animate.py --src DesktopPetForMacApp/Resources/Sprites/idel --path 0 \
  --frames 24 --mode rig --out .sprite-build/out_idel \
  --rig '{"pivot":[151,126],"amp_deg":22,"gates":[["x",153,6,1]],"cycles":1,"mask_feather":4,
          "mask_poly":[[151,124],[167,128],[181,141],[188,155],[186,171],[176,178],[166,173],[159,160],[155,148],[152,138],[148,130]]}'
```
- `pivot [151,126]` = 尾巴根部；`mask_poly` 沿尾巴轮廓圈紧，左界在下半段收到 x≥155 以避开右后腿。
- `amp_deg 22`（±22°，峰-峰 44°）、`cycles 1`（2s 摇一个来回）；>28° 尾巴与后腰接缝开始显硬。
- 验收：后腿 x118-152/y140-182、躯干 x55-148/y85-140、头部 x28-100/y14-85 的帧间像素差必须为 **0**。

### pet 轻微蹭头（当前落地）
```bash
python3 tools/sprite_animate.py --src DesktopPetForMacApp/Resources/Sprites/pet --path 0 \
  --frames 24 --mode rig --out .sprite-build/out_pet \
  --rig '{"pivot":[85,112],"amp_deg":8,"gates":[],"cycles":2,"bob":2,"mask_feather":3,
          "mask_poly":[[66,20],[82,26],[98,37],[112,43],[130,49],[130,67],[116,79],[106,85],[98,91],[94,99],[88,104],[74,105],[62,102],[52,94],[45,80],[46,62],[52,44],[58,28]]}'
```
- `pivot [85,112]` = 脖子根部；`mask_poly` 包住头 + 双耳，右界在 y>90 时收到 x≤98，避开背部隆起。
- 用户反馈原版「歪头动作幅度极大」，现收敛到 **±8°** + `bob 2` + `cycles 2`（2s 蹭两下）。
- 验收：后背 x108-162/y95-178、前腿 x58-108/y118-181、尾巴卷 x112-168/y146-180 的帧间像素差必须为 **0**。
- 基准图就取现有的 pet `frame_00.png`（坐姿眯眼笑），不需重新调 AI。
- 配遮罩时先在 200×200 图上画网格、把多边形叠在图中看红色覆盖区，确认后再出帧；`mask_feather` 3~4 比默认 5 干净。

### 接口

| 接口 | 说明 |
| --- | --- |
| `GET /api/ping` | 连通性 |
| `POST /api/heartbeat` | 心跳：版本/主机/系统/架构/宠物名/状态 |
| `GET /api/devices` | 设备列表（含备注、在线状态） |
| `POST /api/access/verify` | 激活码校验（code + deviceId，支持加密信封） |
| `GET /api/crypto/pubkey` | 载荷加密公钥（SPKI + PKCS#1） |
| `POST /api/admin/login` `/logout` | 账号密码登录，签发 24h 会话（持久化） |
| `GET /api/admin/codes` | 激活码列表 |
| `POST /api/admin/codes/generate` | 生成（count/maxDevices/validDays/note） |
| `POST /api/admin/codes/unbind` `/delete` | 解绑设备 / 删除激活码 |
| `POST /api/admin/devices/note` | 设备备注 |
| `GET /api/weather` | 天气查询（服务端持 Key，按设备限流；Key 存 `PETSERVER_QWEATHER_KEY`） |
| `GET /api/app/latest` | 客户端更新信息（版本/sha256/Ed25519 签名） |
| `GET /download/<file>` | 安装包下载 |

### 后台页面

- `/admin/login` 登录页（密码 RSA 加密传输）
- `/admin` 菜单一：小猫在线列表（可编辑备注，5s 刷新）
- `/admin/codes` 菜单二：激活码管理（生成/复制/解绑/删除/过期时间）
- `/online` 手机版在线列表（免登录）

### data/ 持久化文件

`heartbeats.jsonl`（心跳日志，5 分钟窗口）· `devices.json`（设备快照，重启恢复列表）·
`device_notes.json`（备注）· `activation_codes.json`（激活码）· `sessions.json`（登录会话）·
`private_key.pem`（载荷加密私钥）

## 三、客户端

- 后端地址：`ServerConfig.swift` → `http://101.96.248.75`
- 加密公钥：`PayloadCrypto.swift`（**与后端成对，换服务器必须同步改**）；敏感字段用
  AES-256-GCM + RSA 包裹密钥（混合加密），无长度限制
- 心跳：每 1 分钟上报
- 提醒设置：喝水提醒（间隔 15/30/45/60 分钟或自定义）；天气提醒（每天定时推送今日天气，
  **仅解锁用户可用**——天气接口按量付费），配置存 UserDefaults：`settings.weatherReminder*`
- 更新检查：启动 30 秒后 + 每 6 小时自动；手动入口仅 设置 → 通用设置 → 版本 →「检查更新」
- 更新检查：启动 30 秒 + 每 6 小时 + 右键菜单（30 分钟节流）
- 授权：解锁时记录激活码；随版本检查定期向服务端复核，**仅服务端明确判定失效才收回权限**；
  网络异常保留权限；本地后门码 `456`
- 升级：sha256 + Ed25519 验签 → 分离脚本换包重启（失败回滚）
- 其他：Dock 隐藏（`LSUIElement`）、宠物名首次启动随机分配（16 个名字池）

## 四、发布流程

> 已封装为 Codex Skill：`skills/deploy-cute-pet/`（`~/.codex/skills/` 有符号链接，新会话可直接触发）。
> 一键命令：`./skills/deploy-cute-pet/scripts/deploy.sh v1.0.016 "更新说明"`，
> 加 `--check` 只检查环境；`COMMIT=1` 顺带提交推送。


```bash
cd DesktopPetForMacApp
./release.sh v1.0.008 "给用户看的更新说明"   # 编译→打包→zip→sha256→签名→上传
```

- 私钥：`~/.cute-pet-release/ed25519_private.pem`（**务必备份**；丢失则无法再发布可被客户端接受的更新）
- 上传助手：`~/.cute-pet-release/{scp_put,ssh_run}.exp`（内含服务器 root 密码，**仅存本地，勿入库**）
- 版本号单一来源：`AppVersion.swift`（打包时自动同步 Info.plist）
- 客户端随后自动升级；**同一版本号不要重复发布不同内容**
- 详见 `docs/自动更新与发布流程.md`

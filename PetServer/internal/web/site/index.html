不只是一个桌宠

从陪伴互动到实用工具，一只宠物把「治愈」和「效率」都装进了桌面。

🫧

桌面悬浮 & 拖拽

无边框透明窗口始终置顶，跨桌面 / 全屏共存，鼠标一拖就能挪到任意角落。

🎬

精灵图动画

专注 / 休闲 / 睡觉 / 抚摸 / 躲藏 5 种形象，帧循环驱动 + 渲染层呼吸效果；喝水提醒时复用专注形象，看着就治愈。

🐾

摸摸 & 喂猫条

点一下就提醒，右键抚摸；「喂猫条」让宠物追着你的光标走，互动感拉满。

💧

喝水提醒

按设定间隔（15 / 30 / 45 / 60 分钟，或自己填）自动弹窗提醒，同时播一段专注动画，久坐党记得抬头喝口水。

📊

菜单栏系统监控

CPU / 内存 / 磁盘 / 网络实时可见，还能一键清理内存，给 Mac 减减负。

🔄

自动更新

内置 Ed25519 验签的静默更新，新版本自动下载校验替换，宠物无缝回来。

💬

主动搭话

按你定的间隔主动开口：随机播报一条今日热搜，或提醒还没做完的待办；你开勿扰、它睡着或躲起来时自动闭嘴。

👫

宠物好友互发消息

每只宠物都有一个专属宠物号，互加好友就能留言。对方发来的消息会变成桌面上的常驻卡片，不点关闭它就一直陪着。

🎧

专注跟随 & 自动打盹

只读检测 macOS 勿扰 / 专注模式：你一专注，它也换成专注形象安静陪着；半小时没有动静，就自己睡着。

📸 专属定制 · 解锁可用

把它换成你家主子

不想只当猫奴？上传一张你自己宠物的照片，AI 会自动把它美化成统一的可爱手绘插画形象——保留你家狗子、猫主子的毛色、斑纹和五官，变成桌面上独一份的那一只。

  • 1在「设置 → 通用设置 → 权限」输入校验码，解锁全部功能
  • 2打开「设置 → 宠物状态」，找到「自定义状态图片」
  • 3点对应状态的「上传图片」，选一张宠物照片，AI 自动美化为柔和手绘插画风格
  • 4专注 / 休闲 / 睡觉 / 抚摸 / 躲藏 五个状态可分开设置；生成结果留在本地，App 更新后依然保留，还能在图片历史里用缩略图回看、切回任意一版

三步把宠物接回家

纯 Swift 开发，无第三方依赖，下载安装即用。

1

下载 dmg

点上面的「下载 macOS 版」，会得到一个 cute-pet-*.dmg 文件。

2

拖到「应用程序」

双击打开 dmg，把左边的 cute pet 图标拖到右边的 Applications 文件夹上松手——和装其他 Mac 软件一样。

3

打开宠物

到「启动台」或「应用程序」里双击 cute pet。若提示「无法验证开发者」，右键点图标 → 选「打开」即可。

# 美境宠物姿态素材 Prompt 存档

为 `DesktopPetForMacApp` 生成 5 个状态的宠物姿态图（提醒 warn 已合并进专注，不再生成；新增「躲藏 hide」，贴屏幕边缘时只探出脑袋、一点前胸和一只小爪）。

**静态状态（focus / sleep / hide）每状态 1 帧**，呼吸、状态切换等动画交给 App 渲染层实现。
**动态状态（idel 休闲 / pet 抚摸）：AI 只出 1 张带动作的基准图，24 帧序列用 `tools/sprite_animate.py --mode rig` 骨架式变形合成**（详见 references/prompts.md「三、动画帧」）。不要 AI 逐帧生成，也不要 AI 出多张关键姿态后拼接。

## 核心策略

- 平台：美境 AI 设计师（内网），模型 `gpt-image-2.5-sunburst-vision`
- 身份锚点：真实猫咪照片（银渐层英短）作为参考图；S3 URL 24h 过期需重传
- 输出：5 张 PNG → 手动抠图缩放 → 落到 `Sprites/{state}/frame_00.png`
- `SpriteSheet` 单帧加载即可，呼吸由渲染层缩放实现
- idel / pet 的序列帧用 `DesktopPetForMacApp/tools/sprite_animate.py` 生成：单张基准图 → 抠图统一尺寸 → `--mode rig` 绕骨根做带权重衰减的旋转，正弦驱动 24 帧，天然首尾无缝

## 使用步骤

1. 打开对应状态的 prompt（见 [references/prompts.md](references/prompts.md) 的「一、各状态基准图」）
2. 参考图用 `[@image:#1]` 占位符插入开头，末尾附 `For Image #1: URL: <S3 URL>`
3. `generate.py "<组装后的 prompt>"` 提交 1 张
4. `poll.py` 轮询取图
5. 成品图用后处理脚本抠图并缩放到 200×200 透明画布（见下方「后处理脚本」；hide 贴左边缘、其余居中，参考约束 4、5、6）

## 后处理脚本

`scripts/cut_sprite.py`：纯色/黑底抠图 + 缩放到统一画布，一条命令完成约束 4、5、6 的抠图与落图。

```bash
# hide 躲藏态：贴左边缘、主体高 114
python3 scripts/cut_sprite.py <输入图> <输出.png> --align left --height 114
# 其余四态(idel/sleep/pet/focus)：居中、主体高 162
python3 scripts/cut_sprite.py <输入图> <输出.png> --align center --height 162
```

内部即「四边泛洪判近黑背景 → 最大连通域保主体(顺带去水印) → 等比缩放 → 贴 200×200 透明画布」。`--bg` 调背景阈值(越小越保守，深色毛发被吃就调小、背景没除净就调大)，`--canvas` 改画布边长。依赖 Pillow。

## 通用后缀（保持一致才能五状态风格统一）

```
3头身Q版卡通可爱风格，干净浅色纯色背景，纯白背景，猫身悬浮在背景中，
脚下不要地面阴影、不要投影、不要影子，画面中只有这一只猫，无文字无水印
```

## 关键约束（易踩坑）

1. **背景必须显式写「不要地面阴影」**：模型默认会给猫加一块浅灰投影，抠图时投影与爪子连通会被判成主体，深色壁纸下明显发灰；阈值/连通域去不掉，**只能靠 prompt 从源头规避**。
2. **抚摸态必须显式写「不要出现人的手」**：否则模型会画一只手在猫头上。
3. **不要做多帧**：曾实测 8 帧 bbox 640~794（约 25% 差异），统一尺寸后帧间无动作差异≈静止，白白增加成本。单帧 + 渲染层缩放才是正解。**需要真动画时**也只出 1 张基准图，交给 `--mode rig` 做局部变形（摇尾巴 / 点头）——实测用户会直接说「动的太呆了，像在瞬移」，多关键姿态拼接同样不行；光流位移场插值会把细尾巴扇成一片、把歪头拉变形。
4. **抠图必须连通域**：仅靠「亮度>235 去背景」会把耳朵尖/尾巴当噪点剔除；用 BFS 从边界泛洪判背景 + 最大连通域保主体。
5. **尺寸统一**：成图 1024×1024 → 抠图 → 等比缩到 170×170 → 贴到 200×200 透明画布；实测五状态主体高度统一为 162px，切换不跳动。
6. **躲藏态只画探出来的部分，且必须直立扒边**：写清「上身竖直立起、一只前爪向上抬起扒住画面左边缘、像躲在隐形墙壁后探头」，并显式禁止「趴卧、伏低、下巴支地」——只写「探身偷看」模型会画成前身伏低、下巴前凑的趴姿。头部完整可见、所有可见部分紧贴画面左边缘，另一只爪不画；不要画墙 / 门框 / 屏幕边框，否则会和真实屏幕边缘对不上。落图时主体左边缘对齐画布左边（不居中）、垂直居中，头高按休闲帧对齐（约 55~60px），不要拉到 162px。

# 美境 CLI 生成宠物姿态动画素材 —— Prompt 存档

> 用于给 DesktopPetForMacApp 生成 5 状态（休闲/睡觉/提醒/抚摸/专注）的宠物动画帧。
> 平台：美境 AI 设计师（内网），生成模型：`gpt-image-2.5-sunburst-vision`
> 参考图：项目内置猫咪 `Sprites/idel/idle_0_副本.png`（曾上传 S3 作为身份锚点）

## 用法说明

- 每帧 `generate.py "<组装后的 prompt>"` 提交，再 `poll.py` 轮询取图
- 参考图用 `[@image:#1]` 占位符插入开头，末尾附 `For Image #1: URL: <S3 URL>`
- 通用后缀（保持一致）：`3头身Q版卡通可爱风格，干净浅色纯色背景，画面中只有这一只猫，无文字无水印`

## 二、呼吸循环帧（目前只做了 idel，8 帧）

参考图固定用 idel 姿态图（S3: `...c8c4cde9-2181-42e5-8cb9-18d8ce1cbf2f`），逐帧让 AI 画"呼吸循环第 N 帧"，保持完全一致、仅缩放。

面向**整体缩放做呼吸**（已实现）：

### 帧 0 — 呼气最小（-3%）
```
这是一只猫的呼吸动画第1/8帧（呼气到最小）：与参考图相比，猫咪的毛色、斑纹、脸型、五官、站姿、尾巴、背景完全一致，唯一变化是整体比参考图略微缩小（约3%）身体轮廓内收，像刚吐完气。
```
### 帧 1 — 吸气进行中（+约1.5%，腹部鼓）
```
 ...第2/8帧（吸气进行中，稍鼓）：整个身体比参考图略微放大一点点（约1.5%）腹部熊微鼓起。
```
### 帧 2 — 吸气最饱满（+5）
```
 ...第3/8帧（吸气最饱满）：整个身体比参考图放大最多（约5%）腹部最鼓，像刚吸满一口气即将吐。
```
### 帧 3 — 呼气开始（+1）
```
 ...第4/8帧（呼气开始）：身体比上一帧略收（约比参考图放大1%），腹部开始回落。
```
### 帧 4 — 呼气中段（0%）
```
 ...第5/8帧（呼气中段）：身体回到与参考图基本一致大小（约0%缩放），腹部平。
```
### 帧 5 — 呼气更深（-2）
```
 ...第6/8帧（呼气更深）：身体比参考图缩小约2%，腹部进一步内收。
```
### 帧 6 — 呼气最深（-3%）
```
 ...第7/8帧（呼气到最深）：身体缩小到最小（约3%收缩），腹部收得最紧，像吐完最后一口气。
```
### 帧 7 — 收尾回升（-2%）
```
 ...第8/8帧（准备下一轮吸气）：身体比最小帧略微回弹一点（约2%收缩），腹部开始放松准备再鼓起。
```

## 三、经验 & 已知问题（重要）

1. **AI 帧间大小不可控**：prompt 要 3%、模型实际画 ±10%~25%（8 帧 bbox 实测 640~794，差约 25%）。必须后期做尺寸归一化。
2. **抠图必须连通域**：仅靠"亮度>235 去背景"会把耳朵尖/尾巴当噪点剔。用 BFS 最大连通域保留主体，只剔孤立小噪点。
3. **帧尺寸需统一**：后期统一 resize 到同一像素尺寸（如 170×170）放 200×200 画布，否则动画"忽大忽小"。
4. **统一尺寸后无动作差异**：若 8 帧只有整体大小差异，统一尺寸制大小一致≈静止。呼吸感要么靠 App 渲染层缩放，要么重跑让 AI 只改耳朵/尾巴局部。
5. **通用帧后缀**：`3头身Q版卡通可爱风格，干净浅色纯色背景，画面中只有这一只猫，无文字无水印` 能稳定命中 `gpt-image-2.5-sunburst-vision`。
